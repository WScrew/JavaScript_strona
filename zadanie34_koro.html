1) Instrukcja wyboru → składania teoretyczna.

if (warunek) { instrukcje; }

2) Instrukcja wyboru → schemat blokowy.

Początek → sprawdzenie warunku → (jeśli prawda) wykonanie instrukcji → Koniec (jeśli fałsz) → Koniec

3)Instrukcja alternatywy → składania teoretyczna.

if (warunek) { instrukcje1; } else { instrukcje2; }

4)Instrukcja alternatywy → schemat blokowy.

Początek → sprawdzenie warunku → (jeśli prawda) → instrukcje1 → Koniec (jeśli fałsz) → instrukcje2 → Koniec

5)Operatory porównania.

== (równe)
!= (różne)
> (większe)
< (mniejsze)
>= (większe lub równe)
<= (mniejsze lub równe)

6)Uwaga do operatorów porównania.

Operator == porównuje wartości, a nie przypisuje. Do przypisania służy operator =.

7)Operatory logiczne.

&& (i)
|| (lub)
! (negacja)
