Teoria pętli

1. Pętla for

Konstrukcja:

for (inicjalizacja; warunek; modyfikacja) {
    // kod
}

Opis: Używana, gdy liczba powtórzeń jest znana z góry.

Schemat: [Start] -> [Inicjalizacja] -> [Warunek?] --TAK--> [Kod] -> [Modyfikacja] -> (powrót do warunku) | --NIE--> [Koniec]

2. Pętla while (kontrolowane wejście)

Konstrukcja:

while (warunek) {
    // kod
}

Opis: Sprawdza warunek przed wykonaniem kodu. Może nie wykonać się ani razu.

Schemat: [Start] -> [Warunek?] --TAK--> [Kod] -> (powrót do warunku) | --NIE--> [Koniec]

3. Pętla do while (kontrolowane wyjście)

Konstrukcja:

do {
    // kod
} while (warunek);

Opis: Sprawdza warunek po wykonaniu kodu. Zawsze wykona się minimum raz.

Schemat: [Start] -> [Kod] -> [Warunek?] --TAK--> (powrót do kodu) | --NIE--> [Koniec]
